amina — заметки по деплою и РФ/VPN
================================

1) Всегда открывай приложение по HTTPS с Vercel (не file:// с диска).

2) YouTube-поиск:
   - В Vercel добавь переменную YOUTUBE_API_KEY (YouTube Data API v3 в Google Cloud).
   - Без ключа поиск ходит через публичные зеркала — они часто лежат.

3) Видео YouTube в РФ:
   - В приложении плеер грузится с youtube.com — если у тебя без VPN не открывается, включай VPN или сплит-туннель только для youtube/googlevideo.
   - Код не может обойти блокировку провайдера без своего прокси/приложения.

4) Google «как Лос-Анджелес»:
   - Запросы через встроенный браузер идут на /api/browse-proxy — страница качается с серверов Vercel (обычно не из РФ), плюс в ссылках уже стоят параметры US/LA (uule и т.д.).
   - Аккаунт dxxsmxrl уже учитывается для EN/US в плеере YouTube.

5) Синхрон браузера:
   - Оба должны быть в одной комнате (?room=...).
   - Когда кто-то открывает сайт во вкладке «browser», второму откроется та же панель и тот же iframe (в т.ч. прокси для Google).
